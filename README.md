# カコモン+ (Kakomon Plus)

過去問演習サイトを「もっと快適に」使えるようにした学習 Web アプリのプロトタイプです。
仕組みは既存の過去問演習サイトとほぼ同じまま、**UI/UX の改善**に振り切っています。

## 特徴

| 機能 | 内容 | 提供 |
|---|---|---|
| ◯△✕ で択を絞る | 各選択肢の左のボタンで ◯(有力)→ △(保留)→ ✕(除外)を切替。✕ は打ち消し表示になり、本番と同じ「消去法」ができる | 無料 |
| ペン・マーカー書き込み | 問題カードに赤/青ペン・蛍光マーカーで直接書き込み。消しゴム・全消去つき | 無料 |
| 2つの解答方式 | **一問一答**(解答ごとに即採点・解説)と**まとめて採点**(連続で解いて最後に全問の答え合わせ)をホーム/設定で切替 | 無料 |
| スムーズな進行 | ワンタップ解答 → 即解説 → 大きな「次へ」ボタン。`1`〜`4` キーで解答、`Enter` で次へ。「自動で次へ」設定あり | 無料 |
| 誤タップさせない広告設計 | 広告スペースは**解説の下だけ**。選択肢や「次へ」ボタンには隣接させない | — |
| 模試の自動作成 | 分野バランス型に加え、解答統計から弱点分野を重点出題する**弱点強化型**。タイマー・採点・分野別内訳つき | ✦ プレミアム予定 |
| 学習統計 | 総解答数・正答率・連続学習日数、分野別正答率グラフ、間違えた問題のワンタップ復習 | 無料 |
| ダークモード | 端末設定に追従 + 手動切替 | 無料 |
| レスポンシブ | スマホ縦/横・タブレット・PC に対応。広い画面では問題と選択肢を2カラム表示 | — |
| フィードバック | アプリ内から不具合報告・要望を送信(現状は mailto/コピー。将来はフォームサービスや issue 連携に置換) | 無料 |

配色は集中を妨げないニュートラルグレー基調 + 低彩度ブルーで統一しています(装飾絵文字なし)。

## 動かし方

ビルド不要・依存パッケージなしの静的サイトです。

**一番簡単な方法(サーバー不要)**: `dist/kakomon-plus.html` をブラウザで開くだけ(ダブルクリックでOK)。
アプリ全体を1ファイルにまとめた単一ファイル版です。再生成は:

```bash
node scripts/build-single.mjs   # → dist/kakomon-plus.html
```

開発時はモジュール版をローカルサーバーで:

```bash
# リポジトリ直下で
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages にそのまま公開できます(Settings → Pages → ブランチのルートを指定)。

| 資格 | 問題数 | 内容 |
|---|---|---|
| 1級建築施工管理技士(オリジナル問題) | 45問 | 第一次検定の形式に合わせた練習用問題。建築学/躯体施工/仕上施工/施工管理法/法規 |

ホームの「資格」セレクタで切替でき、解答履歴・統計は資格ごとに集計されます。

### 実際の過去問の取り込み(問題データの管理)

**実際の過去問は収録していません。** 1級建築施工管理技士の試験問題は試験実施団体(建設業振興基金)の著作物であり、無断転載になるためです。収録分はすべて出題形式に合わせたオリジナル問題です。

権利確認済みの過去問データは、アプリ内の「問題データの管理」(`#/import`)から JSON で取り込めます(ブラウザ内の localStorage に保存)。形式は画面内のテンプレート、または次のとおり:

```json
{
  "id": "kenchiku1-r6",
  "name": "1級建築施工管理技士 令和6年(自分用)",
  "categories": ["建築学", "躯体施工", "仕上施工", "施工管理法", "法規"],
  "questions": [
    { "id": "r6-001", "year": 2024, "category": "建築学",
      "text": "問題文", "choices": ["1", "2", "3", "4"],
      "answer": 2, "explanation": "解説(answer は 0 始まり)" }
  ]
}
```

## 収益化と権利のポリシー

- **基本無料**。模試の自動作成など一部機能を将来プレミアム(有料)とする想定です。
- ただし、**資格団体の規約・著作権上、過去問を使った収益化が認められない資格については、広告・課金なしの完全無料で提供します**。資格ごとに規約を確認してから問題を収録します(例:出典明記が条件の団体、商用利用不可の団体など)。
- 内蔵の問題はすべて権利処理が不要な**オリジナルの書き下ろし問題**です。実際の過去問は上記の確認が済んだものから `js/data/exams/` の形式で追加するか、アプリ内の取り込み機能で利用者自身が追加します。

## 構成

```
index.html               SPA シェル
css/style.css            デザイントークン(ライト/ダーク)
js/app.js                ハッシュルーター + テーマ
js/storage.js            履歴・設定・プレミアムフラグ(localStorage)
js/data/questions.js     問題データ(この形式で資格・問題を追加)
js/views/home.js         ホーム
js/views/quiz.js         演習(◯△✕・書き込み・自動進行)
js/views/exam.js         模試(生成・タイマー・採点)
js/views/stats.js        統計ダッシュボード
js/views/settings.js     設定
js/views/feedback.js     フィードバック送信
js/components/drawing.js ペン/マーカー canvas
js/components/chart.js   横棒グラフ(依存なし SVG)
```

データ層(`storage.js` / `questions.js`)とビューを分離してあるため、
アカウント・課金・サーバー同期を導入する際はデータ層の実装だけを差し替えられます。
